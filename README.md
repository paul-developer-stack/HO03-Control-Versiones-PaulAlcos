# HO03 - Control de Versiones

## Descripción del caso práctico

Una empresa de desarrollo de software necesita organizar los archivos de sus proyectos y mantener un historial de los cambios realizados. Para solucionar este problema, se implementará un repositorio en GitHub que permita controlar las versiones, registrar modificaciones y trabajar de manera ordenada mediante ramas.

## Objetivo del repositorio

Implementar el control de versiones utilizando Git y GitHub, organizando los archivos del proyecto, registrando los cambios mediante commits y demostrando el uso de ramas y Pull Requests para integrar modificaciones en la rama principal.
